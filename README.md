# Гастробар «Рехаб» — Демонстрационная версия сайта

Демо-прототип сайта для гастробара и лаунжа **«Рехаб»** (г. Саратов, ул. имени И.В. Мичурина, 108) на чистом HTML, CSS и JavaScript.

## Особенности демо-версии

- **Архетип дизайна:** Журнальная эстетика (Editorial) — асимметричная сетка, тёмная палитра без градиентов, тонкие разделители `1px`, кириллическая типографика (`Cormorant Garamond` + `Manrope`).
- **Пометка демо-режима:** фиксированный баннер в шапке и пометка в футере.
- **Раздел меню:** отображается крупная заглушка **`Н/Д — меню сейчас недоступно`** по требованиям к прототипу.
- **Отзывы:** блок отзывов и оценок на основе открытых данных **Яндекс Карт**.
- **Бронирование:** форма с клиентской валидацией и модальным окном демо-режима (реальная отправка не выполняется).
- **Модульная архитектура:** данные вынесены в `data/data.json` (с локальной копией `js/data.js`), что позволяет без переписывания перейти к финальной `production`-версии с админкой и бронью в мессенджеры.

## Структура проекта

- `index.html` — основная страница
- `css/styles.css` — дизайн-система и адаптивные стили
- `data/data.json` — структурированные данные заведения
- `js/data.js` — автономная копия данных для локального открытия
- `js/app.js` — логика интерфейса, блока отзывов, анимаций и формы бронирования
- `assets/images/` — фотографии заведения (`1.svg`, `2.svg`)
